# Fruit Bats Flag Football Club Website

A high-performance, custom-designed website for the Fruit Bats Flag Football Club in West London.

## Features

✨ **Custom Design**
- Unique SVG mascot illustration
- Professional color scheme (crimson red, slate blue, electric blue)
- Bold, modern typography (Syne + Inter)
- Fully responsive (mobile, tablet, desktop)
- Dark mode & light mode support

📱 **Responsive**
- Mobile-first approach
- Perfect on all screen sizes
- Touch-friendly navigation

🚀 **Performance**
- Single HTML file (no build process needed)
- Minimal dependencies (only Google Fonts)
- Fast loading times
- Optimized for SEO

📧 **Functional**
- Contact form (mailto integration)
- Email links to coaching team
- Social media integration (Facebook, Instagram)
- Navigation anchors to all sections

## Sections

- **Hero** - Eye-catching introduction
- **Championship Pedigree** - Achievements and accolades
- **Who We Are** - Club story and philosophy
- **Our Teams** - U11s, U14s, U17s descriptions
- **Our Coaches** - Coaching credentials
- **Get Involved** - Training details and how to join
- **Contact** - Contact form and information

## Development

### Local Development
```bash
node server.js
# Visit http://localhost:3000
```

### Files
- `index.html` - Main website (all content)
- `server.js` - Node.js HTTP server
- `package.json` - Project metadata

## Deployment

### Railway (Recommended)
1. Push to GitHub
2. Connect GitHub repo to Railway
3. Railway auto-detects and deploys
4. Site lives at `fruitbatsnfl.railway.app`
5. Connect custom domain in Railway settings

### Other Hosting
- Upload `index.html` to any web server
- Point your domain to the hosting

## Customization

To customize the site:
1. Edit `index.html` directly
2. Modify colors in the `:root` CSS variables
3. Update content in the HTML sections
4. Change contact email in the form handler
